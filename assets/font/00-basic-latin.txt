# Basic Latin — the printable ASCII, and the shapes every other block is measured against.
#
# # The cell, and why it is this small
#
# Three wide, five tall for a capital; three tall for a lowercase x-height; one row below the
# baseline for descenders. Six rows and three columns is the whole cell, and every pixel of it is
# a voxel somebody has to build, so the size is not a style choice — it is the price of a word.
#
# Three by five is the floor for an alphabet that has to carry BOTH cases. Below it the shapes
# stop being distinct rather than becoming harder to read: at three by four a capital B, E and S
# all lose the row that holds their middle bar, and at two wide there is no interior left at all —
# no bowl, no counter, nothing to tell an o from a n. Five by seven (what this file used to be)
# reads no better at one voxel per pixel; it costs 35 voxels a letter against 15 and makes every
# sign in the world two and a third times the size for nothing a reader can use.
#
# Three rules break out of that cell, each argued rather than assumed:
#
#   - **M and W are five wide, N is four.** Three strokes do not fit in three columns: two stems
#     need a gap between them, a third needs two gaps, and a diagonal that has one column to fall
#     through is a horizontal bar. Drawn at three, M is H with a heavier middle and N is H with the
#     bar moved a row — which is a pair of letters told apart by one pixel, in the two words a
#     player is most likely to write on a door. Lowercase m and w are five for the same reason.
#   - **The zero is the ring with a bar through it.** A slashed zero needs a diagonal and there is
#     one column to draw it in, so the slash lies down. It is one pixel from the letter O on
#     purpose: that pixel is the convention every reader already knows, and the alternatives were
#     worse — a squared ring is one pixel from `U`, which is a distinction nobody expects.
#   - **i, l, punctuation and brackets are narrower than three**, because an `i` set three wide
#     puts a hole either side of every one and a word is read by its shape.
#
# # What "unmistakable" was measured as
#
# Every pair of the ninety-five was compared cell by cell, and seven letters were redrawn because
# they came out ONE pixel apart: `0`/`U`, `2`/`Z`, `&`/`8`, `H`/`K`, `=`/`z`, `l`/`!` and `u`/`v`.
# One pixel is not a difference at this size — it is a smudge, a bad screenshot, or a voxel somebody
# has not placed yet. What remains one pixel apart is the set where the one pixel IS the meaning:
# `.` against a space, `,` against `;`, `.` against `:`, `O` against `0`, and `O` against `Q`.
# tests/test_font.cpp holds the weaker half of this — that no two characters are the same drawing.
#
# # How to read the format
#
# `top` is how many rows above the baseline the glyph's FIRST row sits at: 5 for a capital or an
# ascender, 3 for a plain lowercase letter, 1 for a comma, 0 for an underscore. A glyph declares
# only the rows it uses, so an `o` is three by three and costs what it looks like. The default is 5.
#
# `advance` is how far the pen moves, INCLUDING the glyph's own width, and defaults to the width.
# The tracking (one pixel) is added on top of it by the layout, so a three-wide letter steps four.
#
# A row is drawn with `#` and `.`. Anything that is not a directive inside an open glyph is a row,
# so a row of dots is a row of dots and can never be read as a comment — which also means there
# can be no comment between a glyph's first row and its blank line. Comments live between glyphs.
