# Emoji — the one place this typeface spends pixels, and the one place it spends colour.
#
# A face at five by seven is a smudge. The smallest cell in which a rounded mouth reads as a mouth
# rather than as a dash is about eleven across, so that is the size, and not one pixel more: these
# are still hand-placed and every one of them is still argued for.
#
# Colour is not decoration here. A yellow circle and a red one are different emoji, and a
# monochrome set is a shrug — so a glyph may carry a palette of its own, written as `palette
# <index> <RRGGBB>` and drawn with that index in place of `#`. Indices are hex digits, so fifteen
# colours still fit one character to a pixel and the drawing stays a picture a person can read.
#
# They sit ON the baseline and rise above the cap height, which is what an emoji does in every
# typeface: it is a picture in the line, not a letter of it.
